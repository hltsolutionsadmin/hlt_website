# HLT Solutions - Futuristic IT Excellence

A premium web application built with the MERN stack, featuring smooth animations with Framer Motion and a high-tech corporate aesthetic.

## Tech Stack
- **Frontend**: React (Vite), Framer Motion, Lucide React, Vanilla CSS
- **Backend**: Node.js, Express, MongoDB (Mongoose)

## Key Features
- **Premium Design**: Futuristic dark theme with glassmorphism and subtle glow effects.
- **Micro-animations**: Smooth transitions and scroll-triggered animations using Framer Motion.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **3D Ready**: Structure designed to easily integrate Spline 3D models.

## Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB (Running locally or Atlas URI)

### Installation

1. **Clone the repository**
2. **Setup Frontend**
   ```bash
   cd client
   npm install
   npm run dev
   ```
3. **Setup Backend**
   ```bash
   cd server
   npm install
   touch .env # Add your MONGO_URI and PORT
   node index.js
   ```
